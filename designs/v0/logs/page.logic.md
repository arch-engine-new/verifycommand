# 操作日志（P7）

> 来源：`prototype/paycenter-admin/index.html` `#page-logs` + `logs` 数组 / `renderLogs()` / `logIt()`；PRD：`paycenter/20-首筑操作后台设计.md` §2（实现口径 JeecgBoot）、§4 P7、§5 A12、§9.1、§9.7、§10 开放项 4。  
> 技术栈 JeecgBoot：操作日志**复用 Jeecg 系统日志（sys_log）扩展**——在其基础上补「动作（业务动作枚举）」「对象」「变更前后值（JSON diff）」字段；界面按 JeecgBoot Vue3（Ant Design Vue）列表页风格（查询区 + BasicTable + 分页），原型仅作结构/字段/交互依据。  
> 支付方式口径：借记/贷记卡已合并为一个支付方式「银行卡」（UNIONPAY_CARD），日志中支付方式开关变更的对象/diff 统一写「银行卡」。

## 操作明细

| 操作 | 触发 | 结果 | 确认 | 角色 |
|------|------|------|------|------|
| 进入操作日志页 | 点击左侧菜单「操作日志」 | 调 A12 操作日志列表（默认按时间倒序、第 1 页），渲染日志表格（切换菜单即刷新，见 20 §9.1） | 无 | 全部登录用户（管理员、运营） |
| 按操作人筛选 | 输入操作人关键字 | 作为查询条件（模糊匹配操作人姓名/账号），点「查询」后生效 | 无 | 全部登录用户 |
| 按动作筛选 | 下拉选择动作 | 作为查询条件（精确匹配动作枚举；「全部动作」= 不限） | 无 | 全部登录用户 |
| 按时间范围筛选 | 选择起止时间（RangePicker） | 作为查询条件（按操作时间区间）（PRD 要求，原型未实现） | 无 | 全部登录用户 |
| 按对象筛选 | 输入对象关键字（商户编码/退款单号等） | 作为查询条件（模糊匹配对象）（PRD 要求，原型未实现） | 无 | 全部登录用户 |
| 查询 | 点击「查询」按钮 / 输入框回车 | 带筛选条件重新调 A12，回到第 1 页 | 无 | 全部登录用户 |
| 重置 | 点击「重置」按钮 | 清空筛选条件并重新查询（Jeecg 列表页默认行为；原型未实现，保留框架默认） | 无 | 全部登录用户 |
| 翻页 / 改每页条数 | 点击分页器 | 带当前条件调 A12 取对应页（PRD 要求服务端分页，原型未实现分页） | 无 | 全部登录用户 |
| 查看变更前后值 | 表格「变更前后」列（diff 较长时悬浮 Tooltip / 点击展开） | 展示 JSON diff 的 before→after 内容；无 diff 显示「—」 | 无 | 全部登录用户 |

> 本页**只读**：无新增/编辑/删除日志操作（日志不可篡改，保留 ≥5 年）。Jeecg 系统日志页自带的删除/清空能力**不得开放**（原型无删除；PRD「保留 ≥5 年」隐含不可删）。  
> 日志写入不在本页发生，由各业务操作触发（见下方「日志来源」），本页仅负责查询展示。

## 主流程

1. 用户点击左侧菜单「操作日志」进入 `/paycenter/logs`。
2. 页面调 A12 操作日志列表（默认按操作时间倒序、第 1 页、每页 10 条），渲染表格：操作人、动作、对象、变更前后值、时间、IP。
3. 用户按需填写操作人 / 动作 / 时间范围 / 对象筛选，点「查询」→ 重新调 A12 刷新列表。
4. 用户翻页或悬浮查看变更前后值详情，结束。

> 仅快乐路径。错误/空态见「状态」。

## 状态

- `loading`：进入页面或查询/翻页时表格显示 loading 遮罩（Ant Design Vue Table loading），查询按钮 loading 防重复提交（PRD 隐含，原型未实现：原型为本地数组同步渲染）。
- `empty`：查询无结果时表格区显示空态「无记录」（原型已实现：`<td colspan="6" class="empty">无记录</td>`；Jeecg 风格为 Table 内置 Empty「暂无数据」）。
- `forbidden`：无操作日志菜单权限的账号不可见菜单；直接访问路由提示「无权限访问」（Jeecg 403 页）。一期管理员、运营均有本页权限（20 §2），故正常不会出现。
- `error`：A12 请求失败 → toast 映射后的错误文案（2s 自动消失，不裸奔错误码，见 20 §9.1），表格保留上次数据或显示空，可点「查询」重试（PRD 要求，原型未实现）。
- `success`：（无写操作，不需要成功提示）

## 字段与列

| name | 类型 | 必填 | 展示 | 语义组件（可选） |
|------|------|------|------|------------------|
| operator（操作人） | string | yes | 表格列 | DataTable 列（显示姓名/账号，如「管理员」「运营」） |
| action（动作） | enum | yes | 表格列 | DataTable 列（字典文本：登录/商户新增/商户编辑/商户启停/开关变更/限额变更/退款发起/退款重试/协议配置变更） |

| operateTime（时间） | datetime | yes | 表格列 | DataTable 列（`YYYY-MM-DD HH:mm:ss`） |
| ip（IP） | string | yes | 表格列 | DataTable 列 |
| operatorKw（操作人） | string | no | 表单（查询区） | FormField / Input，placeholder「操作人」 |
| actionFilter（动作） | enum | no | 表单（查询区） | FormField / Select，首项「全部动作」 |
| timeRange（时间范围） | date range | no | 表单（查询区） | FormField / RangePicker（PRD 要求，原型未实现） |

> 映射 Jeecg sys_log：operator ← `username/userid`，operateTime ← `create_time`，ip ← `ip`；action / target / diff 为扩展字段（或以 `log_content` 结构化存储，后端定）。Jeecg 原有的请求方法、耗时、请求参数等列本页**不展示**。

## 查询参数

| 参数名 | 含义 | 默认值 |
|--------|------|--------|

| beginTime / endTime | 操作时间区间（PRD 要求，原型未实现） | 空（不限；Jeecg 风格可默认近 7 天，以后端为准） |

| pageNo | 页码 | 1 |
| pageSize | 每页条数 | 10 |
| order | 排序 | 按操作时间倒序 |

## 数据契约

| 项 | 值 | 说明 |
|----|----|------|
| volumeClass | unbounded | 每次登录/商户配置/退款都写一条，随业务持续增长且保留 ≥5 年 |
| 增长性 | 随业务增长（每日增 N，N≈登录次数+配置变更+退款操作数） | 量级裁决依据：只增不删，长期累积 |
| 列表分页预期 | server-side | 无界增长，必须服务端分页 + 服务端筛选 |

> 原型与 PRD 不一致：原型为本地数组前端过滤、无分页；以 PRD/数据量级为准——服务端分页查询（A12）。

## 选项数据源

| 字段 | 控件 | 来源 | 意向 API 或字典 type | value | label | 父字段(级联) | 加载时机 |
|------|------|------|----------------------|-------|-------|--------------|----------|
| actionFilter | Select | dict | `pay_admin_log_action`（Jeecg 数据字典） | itemValue（LOGIN / MCH_ADD / MCH_EDIT / MCH_TOGGLE / SWITCH_CHANGE / LIMIT_CHANGE / REFUND_CREATE / REFUND_RETRY / AGREEMENT_CONFIG） | itemText（登录 / 商户新增 / 商户编辑 / 商户启停 / 开关变更 / 限额变更 / 退款发起 / 退款重试 / 协议配置变更） | 无 | mount |

> 原型为硬编码 option（登录/商户新增/商户编辑/启停/开关变更/退款发起/退款重试），终态改为 Jeecg 数据字典。  
> 原型缺陷：下拉项「启停」与日志实际写入的动作「商户启停」不一致，原型中选「启停」筛不出记录；终态统一为字典值，表格列与筛选同源。  
> PRD 要求、原型下拉未包含：「限额变更」「协议配置变更」（§4 P7 记录范围）——已补入字典。  
> 字典 code 与 itemValue 为意向名，后端落库时可调整，但须与日志写入方使用同一枚举。

## 校验

| 规则 | 范围 | 说明 |
|------|------|------|
| 时间区间：开始 ≤ 结束 | beginTime / endTime | RangePicker 天然保证；服务端兜底返回参数错误文案（PRD 要求时间筛选，原型未实现） |
| 文本筛选去首尾空格 | operator / target | 前端 trim 后提交（原型对操作人未 trim） |

> 其余筛选项均可空，无必填校验。

## 权限

- 页级：管理员、运营均可进入（20 §2：运营可用页面含「操作日志」）；Jeecg 菜单权限分配给「管理员」「运营」两个角色。
- 两角色在本页**无操作差异**（均只读查询）；一期不做按商户数据权限隔离，运营可看全部日志（二期按商户分权，20 §6）。
- 删除/清空日志能力不对任何角色开放（保留 ≥5 年）。
