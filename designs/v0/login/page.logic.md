# 登录页（P1）

> 来源：`prototype/paycenter-admin/index.html` `#loginPage` + `doLogin()` / `logout()`；PRD：`paycenter/20-首筑操作后台设计.md` §2、§4 P1、§5 A1、§9.1。  
> 技术栈 JeecgBoot：复用 Jeecg 自带登录（图形验证码、失败锁定、JWT），界面按 JeecgBoot Vue3（Ant Design Vue）登录页风格；原型仅作结构/字段/交互依据。

## 操作明细

| 操作 | 触发 | 结果 | 确认 | 角色 |
|------|------|------|------|------|
| 输入手机号 | 输入 | 填写登录名（登录名=手机号） | 无 | 未登录用户 |
| 输入密码 | 输入 | 密码框掩码输入 | 无 | 未登录用户 |
| 输入图形验证码 | 输入 | 填写图形验证码 | 无 | 未登录用户 |
| 刷新图形验证码 | 点击验证码图片 | 重新获取验证码图片（新 checkKey） | 无 | 未登录用户 |
| 登录 | 点击「登录」按钮 / 回车 | 校验通过 → 调 A1 登录，签发管理 token（24h）→ 按账号所属角色（管理员/运营）进入工作台；写操作日志「登录」；toast「登录成功」 | 无 | 未登录用户 |
| 登录失败 | 登录接口返回失败 | toast 映射后的错误文案（账号或密码错误 / 验证码错误 / 账号已锁定）；刷新验证码；连续 5 次失败锁定 15 分钟 | 无 | 未登录用户 |
| 退出登录 | 顶栏「退出」按钮 | 注销 token，回到登录页 | 无（PRD 未要求确认） | 全部登录用户 |

> 原型与 PRD 不一致：原型为「管理员登录」「运营登录」两个按钮由用户自选角色；以 PRD 为准——单一「登录」按钮，角色由账号绑定的 Jeecg 角色决定。  
> 原型与 PRD 不一致：原型为「获取验证码」按钮（短信验证码样式，演示固定 8888）；以 PRD 为准——图形验证码（Jeecg randomImage），点击图片刷新。  
> 「退出登录」入口在全局顶栏，归属全局布局，此处仅记录其回到本页的行为。

## 主流程

1. 进入 `/login`，自动加载图形验证码图片。
2. 用户输入手机号、密码、图形验证码。
3. 点击「登录」→ 前端校验必填 → 调 A1 管理员登录。
4. 成功：保存管理 token（有效期 24h）与用户信息/角色 → 写操作日志「登录」→ toast「登录成功」→ 跳转工作台（`/paycenter/dashboard`）；运营角色进入后商户配置为只读。

> 仅快乐路径。错误/空态见「状态」。

## 状态

- `loading`：点击登录后按钮进入 loading 态并禁用，防止重复提交；验证码图片加载中显示占位（PRD 要求，原型未实现）。
- `empty`：不适用（本页无列表数据）。
- `forbidden`：账号被锁定（连续 5 次失败，锁定 15 分钟）时提示「登录失败次数过多，账号已锁定，请 15 分钟后重试」（PRD 要求，原型未实现，原型仅在文案中说明不模拟锁定）；账号被停用时提示账号不可用（Jeecg 默认行为）。
- `error`：账号或密码错误 / 验证码错误 / 验证码过期 / 网络错误 → toast 统一文案（2s 自动消失，错误码按 10 文档映射，不裸奔错误码），自动刷新验证码，可重试。原型仅校验密码固定 123456 并提示「密码错误」。
- `success`：toast「登录成功」，跳转工作台。

## 字段与列

| name | 类型 | 必填 | 展示 | 语义组件（可选） |
|------|------|------|------|------------------|
| username（手机号） | string | yes | 表单 | FormField / Input（前缀手机图标） |
| password | string | yes | 表单 | FormField / InputPassword |
| captcha（图形验证码） | string | yes | 表单 | FormField / Input + 验证码图片 |
| checkKey | string | yes | 隐藏（随验证码图片生成） | 无 |

> 原型有「演示账号」提示文案与默认填充值（13800000001 / 123456 / 8888），仅演示用，正式环境不保留默认值。

## 校验

| 规则 | 范围 | 说明 |
|------|------|------|
| required | username | 「请输入手机号」 |
| pattern（11 位手机号，^1\d{10}$） | username | 「请输入正确的手机号」（PRD 规定登录名为手机号，原型未校验格式） |
| required | password | 「请输入密码」 |
| required | captcha | 「请输入验证码」 |
| 服务端：验证码正确且未过期 | captcha + checkKey | 「验证码错误或已过期」→ 刷新验证码 |
| 服务端：失败锁定 | username | 连续失败 5 次锁定 15 分钟；锁定期内提示剩余锁定（PRD 要求，原型未实现） |

## 权限

- 页级：匿名可访问（未登录用户）；已登录用户访问 `/login` 直接跳转工作台（Jeecg 路由守卫默认）。
- 角色由账号决定：管理员 = 全部 7 页全功能；运营 = 工作台/交易查询/退款处理/协议留痕/操作日志 + 商户配置只读（新增/编辑/启停禁用或提示「需管理员权限」）。登录后据此控制菜单与按钮。
- 账号由管理员在后台（Jeecg 用户管理）建号；二期接入首筑统一登录。管理 token 与业务 OpenAPI（app_id + app_secret 换 Bearer 2h）完全隔离。

## 导航

- 路由：/login

- 需权限：否
