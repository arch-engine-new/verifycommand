# 功能进度总览

> 本文件是功能注册表（feature slug + 描述 + 负责人）。
> 完成度由 `/current-status` 实时从 `_pages.md` + `page.manifest.json` + `connectStatus` 聚合，**不手动维护状态列**。
>
> 新增功能时在此表添加一行（feature slug 须与 `page.manifest.json` 的 `feature` 字段一致）。

| feature | 描述 | 负责人 | 备注 |
|---------|------|--------|------|
| fixture-management | 夹具主数据台账与详情 | | fixture-list / fixture-detail |
| checkout-management | 借出申请与在借/超期清单 | | checkout-form / checkout-list |
| return-management | 归还核验（完好回库 / 损坏维修） | | return-form |
| calibration-management | 校准到期预警与锁定看板 | | calibration-board |
