# 产品摘要

## 定位

工厂工具室 Web 工作台（桌面浏览器）。班组长向工具室借夹具，系统拒绝「他人占用」和「校准过期」；仓管核验归还；工艺员维护校准到期看板。本产品同时作为立规（APT）从空仓到运行时验收的狗粮，留下培训/视频可引用的证据。

一句话价值：班组长借夹具，系统挡住占用冲突与校准锁定；仓管核验归还分流；工艺员看到期预警。

## 目标用户

- **班组长**：给本班生产借夹具，查看自己的在借 / 超期单据。
- **工具室仓管**：维护夹具台账，核验归还完好或损坏。
- **工艺员**：维护校准到期日，查看预警与锁定。

## 核心流程

1. 仓管或工艺录入夹具主数据（编码、类型、状态、校准到期日）。
2. 班组长提交借出申请（夹具、预计归还、用途）。
3. 系统校验：必须在库、未过校准期、当前无其他人在借 → 通过则改为在借。
4. 打开在借清单时，预计归还日已过仍在借的单据标为超期。
5. 仓管做归还核验：完好回库；损坏转入维修（不可再借，直到仓管改回在库）。
6. 校准看板：到期前 7 天预警；到期当日及以后锁定，禁止借出。

## 功能需求

### FR-1 夹具主数据

- 仓管 / 工艺可录入与维护夹具：编码、类型、状态、校准到期日。
- 状态机取值：`在库` / `在借` / `超期` / `维修` / `校准锁定`。
- 班组长不能改校准到期日；工艺员不能做归还核验。

### FR-2 借出申请与占用冲突

- 班组长提交借出：选择夹具、预计归还日、用途。
- 通过条件：夹具必须在库、校准到期日 > 今天、当前无其他人在借。
- 同一夹具并发第二人借出必须失败，展示可读原因（含占用信息），不写第二张在借单。

### FR-3 校准锁定

- 校准到期日 ≤ 今天（含当日）的夹具禁止借出，失败文案必须含「校准」，并提示最近校准到期日。
- 到期前 7 天在看板标预警；到期当日及以后即使在库也视为校准锁定。

### FR-4 超期清单

- 打开在借清单时：预计归还日已过且仍在借的单据标为超期。
- 超期列表能正确列出上述单据。

### FR-5 归还核验

- 仓管核验归还：完好 → 夹具回库、本单关闭；损坏 → 夹具转入维修、本单关闭。
- 维修态夹具不可再借，直到仓管改回在库。

### FR-6 狗粮验收配套

- `/verify` 对本实现有报告。
- `$apt-accept --base-url=<本地>` 能按 page.logic 勾选必验点。
- `docs/dogfood/COMMAND-LOG.md` 与 `GAPS.md` 有真实记录。

### 非目标（明确不做）

- App、小程序、条码枪、IoT、自动柜
- SAP / 财务计价 / 多工厂
- 打印标签 PDF
- 在立规源码仓里实现本业务

## 页面清单

| pageId | pageType | title | route |
|--------|----------|-------|-------|
| `fixture-list` | list | 夹具台账 | /fixtures |
| `fixture-detail` | detail | 夹具详情 | /fixtures/:id |
| `checkout-form` | form | 借出申请 | /checkouts/new |
| `checkout-list` | list | 在借 / 超期清单 | /checkouts |
| `return-form` | form | 归还核验 | /returns/new |
| `calibration-board` | list | 校准到期看板 | /calibration |

### 页面职责

- **fixture-list**：夹具主数据列表；筛选状态 / 类型；入口到详情、借出、校准看板。
- **fixture-detail**：主数据 + 借还历史；展示当前状态、校准到期日、是否锁定。
- **checkout-form**：班组长借出申请；校验失败时展示可读原因（占用 / 校准）。
- **checkout-list**：在借单据；超期用色条 + 文案双通道标出（不单靠颜色）。
- **return-form**：仓管归还核验；完好 / 损坏分流。
- **calibration-board**：到期前 7 天预警、到期及以后锁定；禁止从本页绕过锁定借出。

## 数据模型

### 实体 Fixture（夹具）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 主键 |
| code | string | 夹具编码，唯一 |
| type | string | 类型（字典） |
| status | enum | 在库 / 在借 / 超期 / 维修 / 校准锁定 |
| calibrationDueDate | date | 校准到期日 |
| currentCheckoutId | string? | 当前在借单据 id |
| updatedAt | datetime | 最后更新 |

### 实体 Checkout（借出单）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 主键 |
| fixtureId | string | 夹具 id |
| borrowerName | string | 班组长 / 借用人 |
| purpose | string | 用途 |
| expectedReturnDate | date | 预计归还日 |
| status | enum | 在借 / 超期 / 已归还 |
| createdAt | datetime | 借出时间 |
| returnedAt | datetime? | 实际归还时间 |
| returnCondition | enum? | 完好 / 损坏 |

### 实体 CalibrationAlert（校准预警，可由 Fixture 派生）

| 字段 | 类型 | 说明 |
|------|------|------|
| fixtureId | string | 夹具 id |
| calibrationDueDate | date | 到期日 |
| daysRemaining | number | 距到期天数（负数为已过期） |
| level | enum | 正常 / 预警（≤7 天） / 锁定（≤0） |

### 实体 UserRole（角色，原型可用切换器模拟）

| 字段 | 类型 | 说明 |
|------|------|------|
| role | enum | 班组长 / 仓管 / 工艺员 |

### 状态机

```
在库 --借出成功--> 在借
在借 --预计归还日已过--> 超期
在借|超期 --归还完好--> 在库
在借|超期 --归还损坏--> 维修
维修 --仓管改回在库--> 在库
在库 --校准到期日≤今天--> 校准锁定
校准锁定 --工艺更新到期日到未来且仓管确认--> 在库
```

校准锁定即使物理在架也不可借。占用冲突不产生第二张 Checkout。

## 成功标准 / 验收要点

1. 同一夹具两人并发借出，第二人失败且有可读原因。
2. 校准到期（含当日）不可借，文案含「校准」。
3. 超期列表正确列出预计归还日已过仍在借的单据。
4. 损坏归还 → 维修态，不可再借直到改回在库。
5. `/verify` 有报告；`$apt-accept --base-url=<本地>` 能跑必验点。
6. `docs/dogfood/COMMAND-LOG.md` 与 `GAPS.md` 有真实记录。

## 视觉约束（注入原型）

风格：`baoyu-shift-console`（三班控制台）。深蓝灰分层、青色 CTA、琥珀预警；超期/锁定用色条 + 文案双通道；禁止紫色渐变与发光边框堆砌。
