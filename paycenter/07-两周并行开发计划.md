## 6. 风险与预案

| 风险 | 影响 | 预案 |
|---|---|---|
| 银联联调 D9 未通过 | 上线顺延 | 最坏 D12（无 Mock 兜底，C 端与通道同步受阻） |
| 不做 Mock → 测试环境不可用即全线停摆 | C 端/后端联调同时阻塞 | D1 即申请 IP 白名单（含开放时段外访问）；异常类验收用例（UNKNOWN / 超时 / 重复通知 / 验签失败）改人工构造 + 日志核验 |
| 微信子商户未批 | 微信不可用 | 支付宝/银联卡先行，微信灰度（商户 enabled 开关已支持） |
| 微信/云闪付无测试环境（生产联调） | 生产环境联调风险 | 小额真实交易验证 + 灰度试点（M6）控制风险 |
| 退款状态未知 | 退款状态误判 | 未知状态一律走退款查询兜底（SUCCESS 为准） |
| 微信子商户未批 → 灰度期主渠道为支付宝 | 业主支付体验打折 | 接受支付宝/银联卡主渠道 + 引导（微信开通后开关打开） |
| 多物业入网周期 | 二期扩展慢 | 商务提前铺排协议/进件（材料清单已齐，见 08 G34） |
