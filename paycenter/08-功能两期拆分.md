## 三、一期验收标准（Done 定义，7 条全过才算一期完成）

1. **全链路跑通**：业主在 C 端 APP 完成"选账单 → 选支付方式 → 银联 SDK 支付 → 回跳确认 → 缴费记录"全流程（真实银联通道）
2. **可退**：运营/物业通过操作后台发起全额退款，原路退回，账单回写已退
3. **可查**：支付中心/操作后台可按单号、商户、日期查询支付与退款
4. **不丢单**：银联通知丢失场景由超时查单任务补捞，UNKNOWN 一律收敛，无悬挂支付单
5. **不重复**：幂等、账单在途锁定、重复通知防重全部生效
6. **开关生效**：微信未开通时 C 端支付方式页不展示微信；停用商户拒绝新单
7. **灰度通过**：试点物业（1 家）运营 D11-D16 无重大异常 → 全量

> 验收用例见 22 文档（P0 用例 100% 通过方可上线）。

## 四、两期边界原则

1. **一期每多一个功能，二期就晚一周**——2 周只保"能缴、能退、能查、能回写"。
2. 一期砍掉的功能**数据模型不留后账**：交易流水必落、支付单明细表必建、分账字段先留——二期只加逻辑不加表。
3. 一期通过**配置**（商户 enabled 开关）解决"微信未批"问题，不为此做完整开关后台。
4. 一期异常兜底：未明确状态靠**查询接口**收敛；对账二期上线后成为最终兜底。
